# DROPZONE — CS2 case opening demo

Original Next.js demo inspired by the dark CS2 case-opening genre.

## Start
- Node.js 18.17+
- `npm install`
- `npm run dev`
- Visit http://localhost:3000

## Included
- Responsive case catalog and animated opening
- Simulated balance and item inventory
- Simulated item selling
- Upgrade mini-game
- Russian-language UI

All balances, drops and upgrade outcomes are local demo state. No payments, Steam login, trading, wagering or withdrawals are implemented. For production, add a secure backend, database, audited randomness, age/geography controls and legal review.


## Demo balance
The demo starts with a virtual balance of 100,000 RUB. All balances and item values are simulated and have no cash value.
